受電できる場所は、東電エリア全体で7か所しか公表されていない

大規模な電気を使いたい事業者に向けて公表されている変電所の地点は、1都8県で7つ。一方、電気を送りたい発電事業者に向けては、県ごとに百地点単位の空容量が数値で公開されている。同じ送電網について、立場によって情報の解像度がまったく違う。このマップは、その需要側の7地点と、公表されている工業団地・再エネ余力を一枚に重ねたものです。独自の推計値は含みません。

SIGNATURE / 待ち時間は距離で決まる

公表されている概算工期は、変電所からの距離で示されます。275kV系なら半径1km以内で5年程度、5km以内で10年程度。下は7地点それぞれを同じ縮尺（一辺14km）で並べたものです。早く受電できる圏は、思っているより小さい。

出典／東京電力パワーグリッド「大規模供給ポテンシャルマップ」（2026年2月16日作成）、同「ウェルカムゾーンマップ」用地情報（2025年12月時点）、同「予想潮流等一覧表（変電所）」配電用変電所テーブル（茨城・栃木・群馬・埼玉とも2026年8月18日時点）、県境：国土地理院 地球地図日本
再エネ空容量について／逆潮流側の公表値をそのまま表示しています。発電設備の連系可否に関する情報であり、需要側の受電可否とは異なります（東電PGも両者は別物と明記しています）。
座標について／公式7地点は公表された町名をもとにした概算位置です。配電用変電所はOpenStreetMapの地物タグとの名称一致、または変電所名から推定した住所のジオコーディングによるもので、一部に精度の低い地点を含みます。
栃木・群馬・埼玉データの補足／群馬「下久保」と埼玉「美九里」は、東電PGの群馬・埼玉両資料に同一設備が重複掲載されていたため、群馬側のみ1件として計上しています。変電所名・空容量は判明しているものの所在地を特定できなかった5地点（群馬:須田貝・鹿野沢・みやま、埼玉:館橋・竹間沢）は、地図には含めていません。
このマップで示していないこと／以前のバージョンにあった「DC向け余力の近似値」は削除しました。発電者向けデータから需要側の受電余力を試算する方法が成立しないと確認できたためです。実際の受電可否と工期は、事前協議を経た個別検討で決まります。投資判断の根拠には使えません。
